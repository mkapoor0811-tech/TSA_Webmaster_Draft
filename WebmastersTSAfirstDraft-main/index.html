Lesson 1.1: The Limits of if/else Statements
ARCHITECTURAL DIAGRAM: DETERMINISTIC LOGIC VS. MACHINE LEARNING
Figure 1.1: Empirical optimization inverts rule formulation by deriving weights directly from target outcomes.

In your intro computer science class, you write deterministic code. If you want to check if a student passed a quiz, you write an explicit check: if (score >= 70) return "Pass";. You write the logic, feed in the numbers, and the computer simply follows your instructions word for word.

This works great for simple tasks, but it completely breaks down when you try to write rules for messy real-world problems. For example, think about trying to write if/else statements to recognize handwritten numbers on an envelope. Every person draws the number "4" with different slant angles, pen pressures, and stroke gaps. If you tried to write an if statement for every possible pixel variation, you would need billions of lines of code, and a single odd handwriting quirk would still crash the program.

Machine learning flips this relationship upside down. Instead of hand-coding the rules yourself, you give the computer thousands of scanned images (the inputs, X) paired with the correct number label (the targets, Y). The model starts by making random guesses and iteratively adjusts its internal dials until it discovers the visual patterns on its own.

prediction = activation(W * x + b)
Lesson 1.2: How a Single Neuron Makes a Decision
CIRCUIT DIAGRAM: THE SCALAR PERCEPTRON (W * X + B)
Figure 1.2: A single perceptron scales features through weights, offsets threshold with bias, and computes activation.

The fundamental building block behind every modern neural network is called a perceptron. It takes one or more numbers as input, does simple arithmetic, and decides whether to send a signal forward.

The math breaks down into three basic pieces:

  • Input (x): The raw data point the model is looking at (for example, how many study hours a student logged).
  • Weight (w): A multiplier that determines how much that input matters. A large positive weight means the feature strongly pushes the model toward a positive prediction, while a weight near zero means the model essentially ignores that input.
  • Bias (b): A constant number added to the total. Think of bias as shifting the starting threshold. If the bias is a negative number, the model is cautious and needs stronger inputs before it fires. If the bias is positive, the neuron triggers easily.

The neuron combines them using the formula output = activation(w * x + b). When the calculated sum crosses the decision threshold, the neuron activates. Training an AI model is simply the process of testing millions of examples to find the optimal numbers for every w and b.

Lesson 2.1: How Words Become Coordinates in Vector Space
VECTOR SPACE PROJECTION: SEMANTIC GEOMETRY
Figure 2.1: Semantic linear displacement: subtracting masculine attributes and adding feminine attributes translates King into Queen.

Computers cannot read definitions or understand the emotional tone of text. To process words with math, language models convert every word or sub-word into a list of numbers called an embedding vector.

Think of an embedding as a coordinate on a giant graph. On a simple 2D graph, you have an X and Y coordinate like [0.4, 0.8]. In a real model like GPT or BERT, each word lives in a coordinate space with hundreds of dimensions (often 512, 768, or 1536 axes). Each axis quietly tracks an abstract linguistic trait, like how formal, active, physical, or royal a concept is.

Because meaning is stored as geometry, words that share similar contexts naturally clump together in space. We compare their closeness using Cosine Similarity, which measures the angle between the two arrows pointing from the origin:

Cosine Similarity = (Vector A • Vector B) / (Magnitude A * Magnitude B)

A score of 1.0 means the vectors point in the identical direction, while 0.0 means they are at a 90-degree angle with zero shared context. This geometric arrangement makes vector algebra possible: taking the vector for King, subtracting the direction for Man, and adding Woman lands right next to the coordinate for Queen.

Lesson 2.2: The C.R.A.F.T. Prompt Engineering Standard
THE C.R.A.F.T. CALIBRATION MATRIX
CContextSyllabus topic, prior knowledge & bounds
RRoleExpert tutor persona & explicit voice
AActionClear directive verb (contrast/audit)
FFormatStructural constraints (table/schema)
TTargetCognitive depth & specific grade level
Figure 2.2: The five structural boundaries that eliminate hallucinations and calibrate prompt responses.

Large language models do not think or check facts like a search engine; they predict the next most probable word based on statistical patterns. If you give a model a vague prompt like "tell me about mitosis," it gives you a broad, unhelpful summary because it averages across the entire internet.

To turn generative models into accurate study tools, you need to apply clear guardrails using the C.R.A.F.T. framework:

  • Context: Set the exact classroom scope (e.g., "AP Biology Unit 2 cell division exam prep"). This prevents the AI from giving elementary school overviews or college-level biochemistry tangents.
  • Role: Give the AI an explicit persona (e.g., "Act as a strict AP science teacher"). This forces a serious, pedagogical tone.
  • Action: Use an unambiguous directive verb (e.g., "Contrast prophase and anaphase using bullet points"). Avoid passive verbs like "write about."
  • Format: Dictate the layout (e.g., "A 3-column table comparing chromosome position, spindle attachment, and phase order"). Structured formats keep the AI focused and cut down on conversational filler.
  • Target Audience: Define your skill level (e.g., "Written for a 10th-grade honors student"). This calibrates the reading level and ensures the response uses accurate terminology without drowning in jargon.

Lesson 3.1: How the Transformer Attention Mechanism Works
TRANSFORMER ATTENTION ARCHITECTURE: Q, K, V MATMUL FLOW
Figure 3.1: Matrix attention pipeline routing affinity weights through normalized Softmax distributions.

Before Transformers were invented in 2017, language models read sentences one word at a time in order. By the time they reached word 300 in an essay, the early words had mathematically faded from memory—a notorious issue called the vanishing gradient problem.

The Transformer solved this by processing all words in a sentence at the exact same time using Scaled Dot-Product Attention:

Attention(Q, K, V) = softmax((Q * K^T) / sqrt(d_k)) * V

Think of it like three matrices coordinating in parallel:

  • Queries (Q): What the current word is actively looking for to understand its context.
  • Keys (K): The label or tag on every other word in the passage that explains what it offers.
  • Values (V): The actual substantive information contained in each word.

The model multiplies Q * K^T to calculate how relevant every word is to every other word simultaneously. Because multiplying large matrices can create massive numbers that cause the softmax function to plateau, the equation divides by sqrt(d_k) (the square root of the key dimension). This keeps gradients healthy so the model can learn efficiently.

Lesson 3.2: Finding the Lowest Error with Gradient Descent
GRADIENT DESCENT LOSS BOWL CONVERGENCE
Figure 3.2: Error minimization along a parabolic bowl; excessive step sizes overshoot the minimum into divergence.

Whenever an AI model makes a prediction, we measure how far off it was using a loss function. If the model makes terrible predictions, the loss score is high. If it guesses accurately, the loss is close to zero. We visualize this error landscape as a smooth bowl.

Training an AI means rolling a marble down that bowl until it settles at the lowest point, called the global minimum. This process is called Gradient Descent:

new_weight = old_weight - learning_rate * slope

The derivative calculates the steepness of the slope at the marble's current position, and the learning rate sets how big of a step to take downhill:

  • If the learning rate is too small (e.g., 0.0001), training takes forever and wastes huge amounts of computing power.
  • If the learning rate is set too high (e.g., 1.5), the marble takes giant leaps, overshooting the bottom of the bowl and bouncing higher and higher. In machine learning, this is called an exploding gradient, and it ruins the model's training run.

MEASURE

The EU AI Act: Risk Classification Structure
  • Unacceptable Risk (Prohibited): Social credit scoring, behavioral manipulation targeting kids, and mass untargeted facial scanning. Banned completely.
  • High Risk (Strictly Regulated): Systems affecting critical infrastructure, school admissions/grading, hiring algorithms, and law enforcement. Requires bias audits, logging, and human oversight.
  • Transparency Risk: Synthetic media and chatbots. Must clearly tell users they are interacting with AI.
  • Minimal Risk: Video game AI, spam filters, and route navigation. Operates under normal software standards.

Module 04 Capstone: Public District Algorithm Audit

A full audit of an automated educational dropout-forecasting platform submitted to a public school district.

Audit Brief: "EduForecast AI"

+250 XP Available

A vendor is pitching predictive software claiming 92% accuracy in identifying students at risk of failing. The vendor claims zero bias because demographic fields were excluded from the model.

Phase 1: Proxy Variable Identification

Even without explicit demographic tags, algorithms reconstruct protected classes via correlated proxy features:

  • ZIP Codes: Reconstruct socioeconomic status and neighborhood property tax funding.
  • Subjective Discipline Referrals: "Defiance" infractions carry human grader bias, whereas unexcused absences are objective.
  • Home Wi-Fi Logins: Measures domestic broadband access rather than academic effort.

Phase 2: Error Metric & 80% Rule Audit

High aggregate accuracy frequently masks severe disparities in specific student cohorts:

  • False Positives (Type I): Incorrectly labeling an on-track student as at-risk, causing deficit stigma.
  • False Negatives (Type II): Missing a student who urgently needs academic intervention.
Pilot Cohort Test:
Group A Pass Rate: 70% | Group B Pass Rate: 42%
Impact Ratio: 42 / 70 = 60% (Below 80% threshold = Disparate Impact)

Phase 3: Human-in-the-Loop Governance

Mandatory policy requirements before district adoption:

  1. Algorithmic risk tags must never trigger automated class schedule changes or punitive tracking.
  2. Staff hold a right to explanation: counselors must see the top contributing factors behind any score.
  3. Student records cannot be retained by third parties for commercial model training under FERPA.
