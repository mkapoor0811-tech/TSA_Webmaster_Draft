MODULE 01 // FOUNDATIONS

The Engine Room: Machine Learning Mechanics

+250 XP Available

How modern systems transition from manual, rule-based programming to pattern learning using matrix calculations, loss functions, and self-attention.

Lesson 1.1: Classical Logic vs. Empirical Optimization

In standard computer science classes, we write deterministic code: explicit logic using if/else statements and loops. If a student writes a program to calculate grades, the computer executes those exact steps. If an unexpected situation occurs that isn't written into the code, the program fails.

Real-world problems—like reading handwriting, understanding speech, or identifying tumor margins in medical scans—have far too many variations for a programmer to write individual rules. Machine Learning (ML) flips this process:

  • Traditional Coding: Rules + Data $\rightarrow$ Answers
  • Machine Learning: Data + Target Answers $\rightarrow$ Learned Rules

Instead of hardcoding every rule, we give the model pairs of training inputs ($X$) and target answers ($Y$). The computer starts with random guess numbers called weights ($W$) and biases ($b$), calculating an initial guess:

prediction = activation_function(W • input + b)

Through training iterations (epochs), the computer measures its error and adjusts these weights until its predictions match the underlying data patterns.

Lesson 1.2: The Transformer Revolution & Self-Attention

Before modern architectures, language processing used Recurrent Neural Networks (RNNs). RNNs read text one word at a time in order. If an essay had 500 words, by the time the model reached the end, the early sentences had faded from its internal memory. In machine learning, this failure to retain long-term context is known as the vanishing gradient problem.

The Transformer model (Vaswani et al., 2017) changed this by reading all words in a sentence at the exact same time in parallel[span_16](start_span)[span_16](end_span)[span_17](start_span)[span_17](end_span). It uses a mathematical formula called Scaled Dot-Product Attention:

Attention(Q, K, V) = softmax( (Q • K^T) / √d_k ) • V

To understand this intuitively, think of how a student does research in a library:

  • Query ($Q$): What you are currently looking for (the current word being processed).
  • Key ($K$): The index card or title of every other word in the text passage.
  • Value ($V$): The actual information and meaning contained inside each word.

The dot product $(Q \cdot K^T)$ compares the current word to every other word to assign an importance score. Dividing by $\sqrt{d_k}$ stabilizes the numbers so calculations don't explode in high dimensions. The softmax step converts these scores into percentages that add up to 1.0 (100%), allowing the model to know exactly how much attention each word should pay to every other word.

Lesson 1.3: Vector Spaces, Cosine Similarity, & Gradient Descent

Computers cannot read letters; they only understand numbers. To process text, we turn words into lists of numbers called vector embeddings. A typical model maps words into 512, 768, or more mathematical dimensions.

Words with similar meanings end up close together in this coordinate space. We measure how close two words are using Cosine Similarity, which calculates the angle between their vector directions:

Cosine Similarity = (A • B) / (||A|| × ||B||)

A score of 1.0 means the vectors point in the exact same direction (highly related), while 0 means they are completely unrelated. This geometric structure allows for vector math like:

vector("King") - vector("Man") + vector("Woman") ≈ vector("Queen")

To train the model, we calculate its mistake using a Loss Function (like Categorical Cross-Entropy). Then, Gradient Descent uses calculus derivatives to nudge the weights in the direction that lowers the total error for the next attempt.

Lesson 2.1: The C.R.A.F.T. Prompt Engineering Framework

When students type brief, vague prompts like "write an essay about photosynthesis," the model produces generic, repetitive paragraphs. Because language models are statistical prediction engines, vague questions yield average, uncalibrated answers. The C.R.A.F.T. framework adds the necessary boundaries to make responses useful for schoolwork[span_20](start_span)[span_20](end_span)[span_21](start_span)[span_21](end_span):

  • C - Context: Explain the background, subject unit, and specific constraints (e.g., "I am preparing for an AP Biology unit exam on cellular energetics")[span_22](start_span)[span_22](end_span)[span_23](start_span)[span_23](end_span).
  • R - Role: Tell the model who to act as (e.g., "Act as an experienced high school science tutor")[span_24](start_span)[span_24](end_span)[span_25](start_span)[span_25](end_span).
  • Action (A): Use a clear, direct verb (e.g., "Compare," "Analyze," "Highlight common mistakes")[span_26](start_span)[span_26](end_span)[span_27](start_span)[span_27](end_span).
  • Format (F): Request a clean layout (e.g., a 3-column Markdown table or a numbered checklist)[span_28](start_span)[span_28](end_span)[span_29](start_span)[span_29](end_span).
  • Target Audience (T): Define your grade and skill level (e.g., "For a 10th-grade honors student")[span_30](start_span)[span_30](end_span)[span_31](start_span)[span_31](end_span).
UNSTRUCTURED PROMPT: "Explain photosynthesis for my biology homework." Outcome: General summary that misses specific exam rubric details.
C.R.A.F.T. CALIBRATED PROMPT: "Context: AP Biology unit on plant biochemistry. Role: High school biology tutor. Action: Compare the light-dependent reactions with the Calvin cycle. Format: 3-column table detailing input molecules, output products, and cellular locations. Target Audience: 10th-grade student." Outcome: Organized, detailed, and directly aligned with classroom expectations.
Lesson 2.2: Why AI Hallucinates & How to Verify Sources

A common misunderstanding is thinking that an AI model works like a Google search engine. It does not look up real files or read a verified encyclopedia when generating text. Instead, it predicts the next most probable word based on mathematical patterns in its training data.

Because its goal is to produce sentences that sound fluent and convincing, it will gladly invent convincing titles, fake author names, and realistic-looking Digital Object Identifiers (DOIs). In computer science, this is called an AI hallucination.

The High School Fact-Checking Routine:

  1. Never trust generated bibliographies: Never copy citations directly from a chat window into your works cited page.
  2. Look up the DOI directly: Paste the generated title or DOI number into reliable databases like Google Scholar, PubMed, or JSTOR to verify that the study actually exists[span_32](start_span)[span_32](end_span)[span_33](start_span)[span_33](end_span).
  3. Read the real abstract: Confirm that the real human researchers actually reached the conclusion the AI claims they did.
Lesson 2.3: Socratic Dialogue & Code Troubleshooting

The most responsible way to use an AI model for school is as a Socratic coach. Instead of asking it to write a paper or complete an assignment for you, paste in an outline or thesis statement you wrote yourself and instruct it to challenge your reasoning:

"Act as a debate coach. Read my thesis statement on renewable energy and give me the three strongest counterarguments an opponent would make."

Similarly, for computer science homework, paste your own non-working code and ask the model to explain why a runtime error is happening line by line, rather than having it rewrite the program from scratch. This helps you understand your own code and preserves academic integrity.

Lesson 3.1: Algorithmic Bias & The Four-Fifths (80%) Rule

Computer algorithms do not have feelings or personal grudges, but they faithfully reproduce any imbalance present in their training datasets. If a resume-screening model or school admissions algorithm is trained on past data where one group had fewer opportunities, the model learns that pattern as a statistical fact and rates new applicants from that group lower[span_36](start_span)[span_36](end_span)[span_37](start_span)[span_37](end_span).

To mathematically detect discrimination in automated systems, the federal government (EEOC) uses the Four-Fifths (80%) Rule for adverse impact[span_38](start_span)[span_38](end_span)[span_39](start_span)[span_39](end_span):

Selection Ratio = (Pass Rate of Group B) / (Pass Rate of Group A)

If the selection rate for a protected demographic is less than 80% of the rate for the highest group, the tool is flagged for disparate impact[span_40](start_span)[span_40](end_span)[span_41](start_span)[span_41](end_span). For example:

  • Group A (Majority) Pass Rate: 80%
  • Group B (Protected) Pass Rate: 50%
  • Calculation: $50 / 80 = 0.625$ ($62.5\%$)
  • Result: Because $62.5\%$ is below the $80\%$ threshold, the system is discriminatory under federal standards, even if its designers did not intend it to be[span_42](start_span)[span_42](end_span)[span_43](start_span)[span_43](end_span).
Lesson 3.2: Student Privacy & FERPA Guidelines

When you type text into public, free AI chat websites, your inputs are often stored on corporate servers and used to train future model versions. This creates serious data privacy concerns for students and schools.

Under the federal Family Educational Rights and Privacy Act (FERPA), schools must protect student educational records[span_44](start_span)[span_44](end_span)[span_45](start_span)[span_45](end_span). Pasting unredacted student IDs, grade reports, disciplinary notes, or personal medical accommodations into a public AI tool can breach federal privacy laws[span_46](start_span)[span_46](end_span)[span_47](start_span)[span_47](end_span). Personal information must be scrubbed before running research queries, and school apps should keep user data stored locally in the browser.

Lesson 3.3: The Spectrum of Academic Integrity

Using AI in school exists on a clear spectrum, ranging from productive learning aids to clear violations of school honor codes[span_48](start_span)[span_48](end_span)[span_49](start_span)[span_49](end_span):

  • Zone 1: Socratic Study Partner (Ethical Support): Asking AI to explain a math step, test your vocabulary, or generate practice questions. Fully allowed; 100% student authorship[span_50](start_span)[span_50](end_span)[span_51](start_span)[span_51](end_span).
  • Zone 2: Structural Outlining (Allowed with Disclosure): Using AI to critique your essay outline or identify missing arguments. Allowed if your teacher permits it and you disclose how you used it[span_52](start_span)[span_52](end_span)[span_53](start_span)[span_53](end_span).
  • Zone 3: Heavy Automated Paraphrasing (Compromised): Running your own rough draft through an AI rewriter to change the wording and bypass plagiarism checkers. Violates academic honesty because it replaces your original voice with synthetic text[span_54](start_span)[span_54](end_span)[span_55](start_span)[span_55](end_span).
  • Zone 4: Direct Plagiarism (Honor Code Violation): Having an AI generate whole paragraphs, write essays, or invent citations to turn in as your own work. Strict honor code violation subject to disciplinary consequences[span_56](start_span)[span_56](end_span)[span_57](start_span)[span_57](end_span).

MODULE 04 // CAPSTONE AUDIT

Synthesis Capstone: High School AI Systems Auditor

+250 XP Available

Synthesize foundations, prompt engineering, and ethical governance to conduct an end-to-end algorithmic audit of an automated educational forecasting system[span_58](start_span)[span_58](end_span)[span_59](start_span)[span_59](end_span).

Phase 1: Procurement Audit & Proxy Variable Identification

Imagine your school board is considering purchasing an automated platform called "EduForecast AI" to predict incoming 9th graders at risk of course failure. The software vendor claims their model is 92% accurate and completely objective because it excludes race, gender, and household income.

As a student auditor, your first responsibility is to evaluate proxy variables. Even when sensitive demographic traits are deleted, algorithms frequently reconstruct them through correlated indicators:

  • ZIP Codes: Highly correlated with neighborhood wealth, property tax bases, and historical redlining.
  • Historical Disciplinary Referrals: Documented civil rights studies show subjective infractions (like "disruptive behavior") are disproportionately applied to minority students compared to objective infractions.
  • Home Internet Bandwidth Logs: Directly mirrors family economic status rather than student academic capacity.

When an algorithm trains on these proxies, it bakes historical inequities directly into its mathematical weights.

Phase 2: Error Metric Analysis & The Disparate Impact Ratio

A single "accuracy" percentage is dangerous in high-stakes education. An algorithm can have 90% overall accuracy simply because 90% of students pass, while performing with unacceptable error rates on minority cohorts.

Auditors must calculate the False Positive Rate (FPR) and False Negative Rate (FNR) across subgroups:

  • False Positive (Type I Error): Incorrectly labeling a student as "at-risk." While this triggers tutoring, it can also lead to deficit stigma and lower academic expectations from teachers.
  • False Negative (Type II Error): Incorrectly labeling an at-risk student as "safe," denying them necessary intervention resources.

Worked Audit Scenario:

EduForecast is tested across a pilot cohort of 200 students. The automated intervention recommendations yield the following selection rates for advanced academic placement:

  • Benchmark Group A Selection Rate: 70% ($0.70$)
  • Protected Group B Selection Rate: 42% ($0.42$)
  • Disparate Impact Equation: $\frac{0.42}{0.70} = 0.60$ ($60\%$)

Because $60\%$ is substantially lower than the federal 80% (Four-Fifths) threshold, the algorithm produces legally actionable disparate impact and cannot be deployed in its current state.

Phase 3: The Human-in-the-Loop Governance Framework

To safely govern machine learning in public schools, student auditors recommend a three-tiered oversight framework:

  1. No Fully Automated Actions: Algorithmic scores should serve strictly as optional flags for human counselors, never as automatic triggers for schedule changes, course tracks, or disciplinary notes.
  2. Mandatory Explainability (Right to Explanation): If a student is flagged, counselors must be able to view the top three driving features rather than receiving a single unexplainable score from a black box.
  3. FERPA & Data Minimization: District student data cannot be retained by the vendor to train future proprietary commercial models.
